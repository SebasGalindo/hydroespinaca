# Hydroespinaca

## Descripción
Estructura del proyecto para Hydroespinaca.

## Contenido
- **frontend**: Aplicación React con Vite y Tailwind.
- **shared**: Proyecto .NET con utilidades comunes.
- **hardware-project**: Servicios relacionados con sensores y actuadores.
- **software-project**: Servicios de autenticación, gateway, y otros.
- **deploy**: Configuración de Mosquitto y Nginx.
